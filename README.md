# Family CFO

Личный финансовый консультант семьи. Приложение отвечает на вопросы:

- сколько денег у семьи **сейчас** и сколько из них **действительно можно потратить**;
- сколько ещё можно потратить **по каждой категории** до конца месяца;
- куда уходят деньги и где перерасход относительно обычного уровня;
- что будет **в конце месяца** и в следующем месяце;
- как идут цели, долги и финансовая подушка;
- что конкретно стоит изменить и сколько это даст.

Интерфейс на русском, для iPhone (PWA), работает офлайн. Данные хранятся **только на устройстве**.
Банковских API, импорта выписок и платных сервисов нет: новые операции вводятся вручную.

---

## Запуск

Нужен Node.js 20+.

```bash
npm install          # один раз
npm run dev          # http://localhost:5173 (и адрес в локальной сети)
```

Проверки:

```bash
npm test             # тесты финансовых расчётов (vitest)
npm run typecheck    # проверка типов TypeScript
npm run build        # production-сборка в dist/
npm run preview      # посмотреть собранную версию
```

## Как пользоваться

| Экран | Что там |
|---|---|
| **Главная** | «Можно потратить сейчас» с расшифровкой, план трат по категориям до конца месяца, траты месяца, прогноз, «Что изменилось», главные выводы CFO |
| **CFO** | Индекс устойчивости 0–100, выводы в формате «Что → Почему → Что сделать → Эффект» с уровнем уверенности, где можно сэкономить, регулярные платежи |
| **+** | Быстрое добавление: расход, доход или перевод. Категория подставляется по описанию |
| **Операции** | Подтверждение платежей, история с поиском, регулярные платежи |
| **Ещё → Бюджет** | План месяца (подушка → необходимое → желания), конверты с ручной правкой, факт / обычно / рекомендовано |
| **Ещё → Цели и долги** | Финансовая подушка (3 и 6 месяцев), цели с ежемесячным взносом, займы |
| **Ещё → Семья** | Доход, общие и личные расходы каждого члена семьи |
| **Ещё → Настройки** | Тема и акцент (синий / розовый), члены семьи, источники денег и остатки, категории, запомненные правила, резервная копия, сброс |

Главные правила учёта:

- **Перевод** между своими счетами (карта → наличные, карта → накопления) — не расход и не меняет общий капитал.
- **Снятие наличных** вводите как перевод «Карта → Наличные», а покупки за наличные — как расходы с источником «Наличные».
- **Регулярные платежи** в свою дату попадают в «Ждут подтверждения»: проверьте в банке и нажмите «Да» или «Нет».
  До подтверждения сумма уже вычитается из «Можно потратить».
- **Будущая операция** (дата в будущем) участвует в прогнозе и в «Можно потратить», если попадает в текущий месяц.
- Если исправить подсказанную категорию, приложение запомнит выбор («REWE → Продукты»).

## Как установить на iPhone

1. Опубликовать папку `dist/` на любом бесплатном статическом хостинге, например GitHub Pages.
   В сборке **нет личных данных**: это пустое приложение.
2. Открыть адрес в Safari → «Поделиться» → «На экран Домой».
3. Переслать себе на iPhone файл `private/family-cfo-start.json` (AirDrop или iCloud Drive) и в приложении нажать
   **«Загрузить мои данные»**.

## Резервная копия

- **Сохранить:** Настройки → «Сохранить резервную копию». На iPhone откроется меню «Поделиться», выберите «Сохранить в Файлы».
  Приложение напомнит о копии, если её не было 14 дней.
- **Восстановить:** Настройки → «Восстановить из копии» и выбрать `.json`-файл. Текущие данные будут заменены.
- Это только копия состояния приложения. Банковские выписки приложение не принимает.

## Где что находится

```
src/engine/          финансовое ядро: чистые функции без UI, покрыты тестами
  types.ts           модель данных (суммы в центах, даты YYYY-MM-DD)
  balances.ts        балансы счетов, общий капитал
  available.ts       «Можно потратить сейчас», обязательства, ожидаемый доход
  plan.ts            план месяца: сначала подушка и долги, потом необходимое, потом желания
  allowances.ts      конверты: сколько осталось по категориям до конца месяца
  recurring.ts       регулярные платежи, их даты и подтверждение
  stats.ts           помесячная статистика, «обычный» уровень (медиана)
  budget.ts          рекомендуемый бюджет (от фактических данных, не 50/30/20)
  forecast.ts        прогноз на конец месяца и следующий месяц
  goals.ts           цели и долги
  health.ts          финансовая подушка, индекс устойчивости
  insights.ts        выводы CFO
  contribution.ts    вклад членов семьи
  changes.ts         блок «Что изменилось»
  categorize.ts      автокатегории и запоминание исправлений
  engine.test.ts     тесты (включая 6 обязательных из ТЗ)
src/storage/         хранение (localStorage за интерфейсом StorageAdapter) и резервная копия
src/state/store.tsx  состояние приложения и действия
src/ui/              экраны и компоненты
public/              PWA: manifest, service worker, иконки
private/             НЕ публикуется (.gitignore)
  build_seed.py      одноразовая сборка начальных данных из выписок
  family-cfo-start.json  начальные данные = файл резервной копии
```

**Начальные данные** собраны скриптом `private/build_seed.py` из банковских выписок (PDF; остатки
сверены до цента). Все допущения видны в приложении: Настройки → «Допущения в начальных данных».
Что было неизвестно, помечено низкой уверенностью или «недостаточно данных».

## Как изменить

- **Категории** добавляются и редактируются в приложении: Настройки → Категории. Там же отмечается «Необходимое»
  (CFO не предлагает резко сокращать такие траты). Базовый набор для «Начать с нуля» — в `src/storage/backup.ts`
  (`emptyAppData`).
- **Остаток счёта:** Настройки → Источники денег → «Остаток сейчас». Это корректировка, история не меняется.
- **Подушка и конверты:** Бюджет → «В подушку в месяц» (пусто — считает приложение), нажмите на конверт, чтобы задать свою сумму.
- **Параметры расчётов** — константы в ядре: лимиты сокращения (`CUT_CAP_*` в `budget.ts`), веса индекса
  устойчивости (`health.ts`), период «обычного» уровня (6 месяцев, `usualLevels` в `stats.ts`).
- **Хранилище** заменяется реализацией `StorageAdapter` в `src/storage/storage.ts`: IndexedDB, сервер синхронизации для
  двух телефонов и т. п.

## Ограничения первой версии

- Одно устройство. Общий доступ с двух телефонов требует сервера синхронизации (следующий этап).
- Остатки счетов, по которым не было выписок, нужно указать в Настройках.
- Инвестиции, налоги, банковская синхронизация сознательно не реализованы.
